# ⏰ WakeArena

### The Smart Alarm Clock You Can't Lie To

WakeArena is an Android alarm app designed to make waking up more active and accountable.

Instead of simply dismissing an alarm, users complete a short cognitive challenge before they can stop it.

## ✨ Features

* ⏰ Task-based alarm dismissal
* 🧠 5 brain-waking mini games
* 🔥 Wake-up streaks
* 🪙 Coins and rewards
* 🏆 Global leaderboard
* 🚨 Escape and penalty system
* 🎟️ TickPass for emergency dismissal
* 🔔 Alarm notifications and full-screen alerts
* 🔄 Alarm restoration after device restart

## 🧠 Mini Games

WakeArena includes five short cognitive challenges:

1. **Visual Memory**
2. **Colour Paint**
3. **Sequence Memory**
4. **Ascending Order**
5. **Copycat**

The challenges require active interaction before the alarm can be dismissed.

## ⏰ How It Works

1. Set an alarm.
2. When the alarm rings, start the assigned challenge.
3. Complete the challenge.
4. Dismiss the alarm.
5. Earn coins and maintain your streak.

Escaping an alarm contributes to the user's escape count and applicable penalties.

## 🪙 Rewards & Accountability

WakeArena combines alarms with a reward and accountability system.

* Earn coins by completing alarm challenges.
* Build wake-up streaks.
* Track escaped alarms.
* Compete on the global leaderboard.
* Escaped alarms can result in penalties.

## 🏆 Global Leaderboard

The global leaderboard allows users to compare their:

* Coins
* Streaks
* Escapes

## 🎟️ TickPass

TickPass provides an emergency option for dismissing an alarm without completing the normal challenge.
